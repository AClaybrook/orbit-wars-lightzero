1. Exact 8× D4 Dihedral Augmentation (features.py)

augment_obs_d4 transforms all 12 spatial planes and rotates/reflects 2D fleet momentum (vx, vy) to 0.0 error.

  • 10,365 multi-opponent boards → 82,920 symmetric states
  • Eliminated overfitting: val value MSE dropped steadily 0.2985 → 0.2660

2. Search-Distilled Expert Iteration (pretrain_alphazero.py)

Generated 155 2P & 4P FFA games (including wd_bestv6 and wd_heuristic) with active-rollout Q-distillation.

  • 2,940 search-distilled Boltzmann stance targets (softmax(Q / 0.035))
  • 76.4% held-out win/loss sign accuracy, 79.2% top-1 stance match

3. D4-Invariant Residual Global Cue (features.py)

Channel 11 encodes sun mask + time progress + global 2P/4P balance so residual blocks learn pure spatial & tactical corrections.

  • Wider 64-unit value & policy FC heads (~2.3 ms/fwd on 1 CPU thread)
  • 100% standard LightZero AlphaZeroModel checkpoint (~1.4 MB)

4. Neural-Prior Ordered Active MCTS (mcts_agent.py)

Evaluates 8 curated full-turn stances in neural-prior order with active-opponent 2P & 4P rollouts.

  • torch.set_num_threads(1) + strict per-ply deadline guards
  • 4P tuned sub_stride=6 (101–142 ms mean, <410 ms max)
