Why PT-v2 Broke Through (0% → 33.3% vs #2)

1) Decoupled Factorized Launch + Multi-Head Q·K Target Attention: Stopped variable legal-target counts from distorting launch probability (val_launch 41.0% → 62.2%, l_f1 = 91.1%, val_tgt = 89.6%). 2) 14-Channel Per-Timestep Orbital Timeline + 3-Block ResConv1D + GeGLU: Gave the network exact 20-tick future `(dx_t, dy_t, r_t, cap_need_t)` orbital geometry. 3) 71.9k-Board Iterative Soft-KD DAgger + Tightly Anchored GPU PPO: Drove `val_kl = 0.098`, then Wave 1 PPO doubled Boss win rate `16.7% → 33.3%` while keeping `akl = 0.075` and `aux = 96.5%`.

3× DirectML RL Speedup Stack (91s → 31.5s/iter)

1) Vectorized NumPy Physics + 2P Shared Cache: Replaced 2.7M Python `math.hypot` calls/game with 1-shot C broadcasts — bit-exact (`max_diff = 5.96e-8`, `0` mismatches) and 3.86× solo / 6.53× 2P faster. 2) B=8 Lockstep CPU Rollouts + `compute_frac=False` + TTA Edge Broadcast: 2.12× faster rollouts & live `8× D4` latency cut `43.4 ms → 33.3 ms`. 3) Cached Ref Log-Probs + `--async-rollout` + `--ppo-epochs 2`: Hides 100% of CPU rollouts behind RX 6950 XT GPU updates (`roll_wait = 0.0s`, `31.5s/iter`).

Reproducible Gen 12 (4.31M PT-v2) Soft-KD + Fast Pipelined DirectML PPO Commands

# 1. Train 4.31M PT-v2 Soft-KD on 71.9k float16 DAgger boards (val_kl=0.098, l_f1=91.1%, val_tgt=89.6%)
python scripts/distill_soft_kd.py --dataset-cache gen12_ptv2_r3_all_f16.npz --resume "" \
  --epochs 20 --batch-size 128 --lr 4.5e-4 --weight-decay 4e-4 \
  --midgame-weight 1.0 --comet-weight 1.2 --hold-boost 1.0 --launch-boost 1.0 --launch-bce-weight 0.25 \
  --feature-version 2 --arch-version 2 --d-model 256 --n-heads 8 --n-layers 6 --dim-ff 512 \
  --contiguous-val --device dml --out checkpoints/planet_transformer_gen12_4m_ptv2_kd.pt

# 2. Fast Pipelined KL-Anchored DirectML League PPO (~31.5s/iter with B=8 rollouts + async overlap)
python scripts/rl_finetune_transformer.py \
  --init checkpoints/planet_transformer_gen12_4m_ptv2_kd.pt \
  --fixed-anchor checkpoints/planet_transformer_gen12_4m_ptv2_kd.pt \
  --pool checkpoints/planet_transformer_gen11_4m_ppo.pt checkpoints/planet_transformer_gen10_4m_ppo.pt \
  --iterations 60 --mirror-pairs 24 --workers 8 --rollout-batch 8 --async-rollout --ppo-epochs 2 \
  --batch-size 256 --device dml --lr 1.5e-5 --kl-coef 0.05 --anchor-kl-coef 0.05 --aux-coef 0.15 \
  --temperature 0.60 --opp-temperature 0.45 --max-steps 260 --launch-threshold 0.53 \
  --force-all-in --two-player-only --no-weak-opps --out checkpoints/planet_transformer_gen12_4m_ptv2_ppo.pt

# 3. Evaluate Gen 12 Champion vs. #2 Hober Malloc (1800.1) & run Boss Forensics
